Sintaxe e Características do Java

O Java foi projetado para ter uma sintaxe familiar para programadores C e C++, mas eliminando complexidades desnecessárias. O código-fonte é compilado para um formato intermediário chamado bytecode, que é executado pela Máquina Virtual Java (JVM).

Algumas das principais características da linguagem incluem:

  • Independência de plataforma: Escreva uma vez, execute em qualquer lugar (WORA).
  • Gerenciamento de memória: Feito de forma automática pelo Garbage Collector.
  • Orientação a Objetos: Tudo em Java (exceto os tipos primitivos) é um objeto.
